# Phishing Analysis

A practical phishing email analysis repository focused on SOC and Blue Team investigation techniques.

## Project Overview

This repository documents practical investigations of phishing emails using a structured analysis methodology. Each investigation focuses on identifying indicators of compromise (IOCs), analyzing email headers and authentication mechanisms, enriching extracted indicators, and correlating evidence to determine the nature and potential impact of the activity.

The investigations are based on `.eml` samples and include supporting screenshots documenting relevant stages of the analysis.<br>

## Methodology

The investigations follow a structured workflow:

1. Initial Triage
2. Safe Handling & Evidence Preservation
3. EML Analysis
4. IOC Extraction
5. Header & Authentication
6. IOC Enrichment
7. URL / Attachment Analysis
8. Evidence Correlation
9. Final Assessment

See [methodology.md](./methodology.md) for the complete methodology.
